# مهرینه — نسخه قابل اجرای وب و پوسته اندروید

## مشاهده سریع
فایل `website/app.html` را در مرورگر باز کنید. برای اجرای محلی پایدارتر:

```bash
cd website
python -m http.server 8000
```
سپس به `http://localhost:8000/app.html` بروید.

وب‌سایت اصلی نیز در `website/index.html` حفظ شده است.

## ساخت APK بدون Android Studio
۱. محتوای این ZIP را در ریشه یک Repository گیت‌هاب قرار دهید (پوشه `.github` را نیز آپلود کنید).
۲. در GitHub به Actions > Build Mehrineh Android APK > Run workflow بروید.
۳. پس از سبز شدن اجرای workflow، فایل Mehrineh-Android-Debug-APK را از بخش Artifacts دانلود کنید.
۴. ZIP خروجی Artifacts را باز کنید و `app-debug.apk` را روی گوشی اندرویدی نصب کنید.

این APK از نوع debug و مناسب آزمون است، نه نسخه انتشار فروشگاهی. اولین build باید در GitHub انجام و خطاهای احتمالی محیط بررسی شوند؛ APK از پیش ساخته‌شده داخل ZIP نیست.

## امکانات پیاده‌سازی‌شده
- داشبورد واکنش‌گرا، مخاطبان تصویری قابل توسعه، تماس با شماره‌گیر
- تم سبز، آبی، قرمز و کنتراست بالا؛ چهار اندازه متن
- تقویم شمسی امروز، ثبت یادآوری، اعلان هنگام باز بودن صفحه و خواندن با SpeechSynthesis
- اعلام حال و درخواست کمک؛ پنل خانواده در همان ذخیره‌ساز مرورگر
- شبیه‌ساز پنج‌مرحله‌ای خرید اینترنتی با ثبت پیشرفت
- چت فرمان‌محور و تشخیص گفتار در مرورگرهای پشتیبان؛ سفارش آزمایشی با تأیید
- میان‌بر وب برنامه‌های پرکاربرد
- نسخه قبلی سایت با صفحات آموزش، اشتراک، وبلاگ و غیره

## محدودیت‌های مهم
- حساب‌ها و داده‌های جدید در LocalStorage ذخیره می‌شوند و **بین دو گوشی همگام نیستند**.
- پیام‌ها و درخواست کمک، اعلان پوش به گوشی فرزند نمی‌فرستند.
- ویدئوی واقعی در بسته نیست؛ محل اتصال آن در صفحه آموزش مشخص است.
- چت از منطق فرمان‌های محلی استفاده می‌کند، نه یک مدل AI آنلاین.
- موتور گفتار/میکروفن در Android WebView و مرورگرهای مختلف ممکن است متفاوت باشد و نیازمند تست واقعی است.
- یادآوری در پس‌زمینه و زمانی که برنامه بسته است تضمین نشده است.
- میان‌برها فعلاً به وب‌سایت رسمی برنامه‌ها می‌روند؛ باز کردن اپ نصب‌شده نیازمند تنظیم intent اختصاصی است.
- برای نسخه عملیاتی: Supabase یا بک‌اند امن، Firebase Cloud Messaging، مجوزهای دستگاه، اعلان محلی بومی، API هوش مصنوعی در سمت سرور و محتوای ویدئویی لازم است.

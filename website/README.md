# مهرینه — نسخه‌ی ۲ (سایت + اپلیکیشن)

HTML + CSS + JS خام. `index.html` را باز کنید (برای آیکن‌ها و فونت اینترنت لازم است).

## هر تغییری را کجا انجام دهم؟

| می‌خواهم... | فایل |
|---|---|
| رنگ، فونت، گوشه‌ها را عوض کنم | `css/tokens.css` |
| نوبار یا فوتر را عوض کنم | `js/ui-common.js` (بخش‌های «نوبار» و «فوتر») و `css/layout.css` |
| لینک دانلود اپلیکیشن بگذارم | `js/config.js` |
| ظاهر دکمه، کارت، فرم | `css/components.css` |
| ظاهر قهرمان، شبیه‌ساز، داشبورد | `css/pages.css` |
| آموزش یا شبیه‌ساز جدید | `data/lessons-data.js` (`tier: 0|1|2`، `sim` اختیاری) |
| وبلاگ، فیلم، قیمت اشتراک | `data/content.js` |
| منطق ثبت‌نام، ورود، خرید | `js/store.js` |
| رفتار هر صفحه | `js/pages/<نام صفحه>.js` |

HTML هر صفحه فقط ساختار است؛ اسکریپت و استایل داخل صفحه‌ها نیست.

## پوشه‌ها
- `css/` توکن‌ها، پایه، چیدمان، کامپوننت‌ها، صفحه‌ها (به همین ترتیب بارگذاری می‌شوند)
- `js/` تنظیمات، منطق، رابط مشترک؛ `js/pages/` رفتار هر صفحه
- `data/` محتوا
- `assets/img/` عکس‌ها: hero, elder, family, app, blog-1..4, video-1..4, lesson-<id>.jpg
